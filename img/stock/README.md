# img/stock — иллюстративные изображения

Здесь лежат **иллюстративные** (стоковые или сгенерированные для сайта) фотографии для
страниц инвестиций, владельцам, плиток главной и т. п. Это не фото конкретных объектов
агентства. Реальные объекты — только в `img/listings/` (синхронизируются из Notion/Dropbox),
фото Будвы — в `BG_images/`.

## Правила

- Изображение должно быть **обобщённым**: без узнаваемых чужих брендов, вывесок, номеров
  машин, лиц крупным планом и текста в кадре.
- **Никогда не выдавать за реальный объект.** Alt-тексты (из i18n) — описательные и общие:
  «Побережье Черногории», «Бутик-отель у моря — иллюстрация». Нельзя писать «наш отель в
  Будве», указывать адрес, цену или площадь рядом с такой картинкой как с фото объекта.
- Только изображения, на которые у нас есть права (собственная генерация или лицензия,
  допускающая коммерческое использование на сайте). Источник/лицензию — в таблицу ниже.
- Формат исходника: JPEG (sRGB), ширина ≥ 2048 px (для широкого hero — до 2688 px),
  пропорции 3:2 для плиток, 21:9 для широкого hero. Без EXIF с геоданными.
- Имена: `<раздел>-<тема>.jpg`, латиница, нижний регистр, через дефис
  (`invest-hotel.jpg`, `owners-interior.jpg`).

## Как использовать

1. Положить файл в эту папку.
2. Запустить `python tools/optimize_images.py` — появятся WebP 480/800/1280/1600/2048 и
   JPEG-фолбэк 1280 в `img/derivatives/img/stock/…`, запись в `img/derivatives.json`.
3. В шаблонах ссылаться на **исходный** путь через хелпер:
   `{{ img("img/stock/invest-hotel.jpg", t("<ns>.<ключ alt-текста>"), sizes="(min-width: 900px) 33vw, 100vw") }}`.
   Если файла нет, `img()` должен деградировать изящно (шаблон не падает).

Удалённый отсюда файл при следующем запуске `optimize_images.py` автоматически теряет свои
производные в `img/derivatives/`.
