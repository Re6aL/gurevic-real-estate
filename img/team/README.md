# img/team — фотографии для страницы «О нас»

Страница `about/` (шаблон `src/templates/pages/about.html`) показывает портрет
Ильи Гуревича, если существует файл **`img/team/ilia.jpg`**. Пока файла нет, вместо фото
выводится монограмма (тёмно-синяя панель с золотыми буквами «ИГ» / «IG» из
`i18n/<lang>/about.json → portrait.monogram`) — битой картинки не будет.

## Как добавить фото

1. Подготовить портрет:
   - вертикальный, пропорции **4:5**, рекомендуемый размер **1200×1500 px** (минимум 800×1000);
   - JPEG, цветовой профиль sRGB, без геоданных в EXIF;
   - лицо в верхней трети кадра, спокойный нейтральный фон; шаблон обрезает фото
     по пропорции 4:5 (`object-fit: cover`), поэтому важное держать ближе к центру.
2. Сохранить как `img/team/ilia.jpg` (латиница, нижний регистр).
3. Сделать адаптивные версии (WebP 320/480/800/1200 + JPEG-фолбэк, запись в `img/derivatives.json`):

   ```
   python tools/optimize_images.py
   ```

4. Пересобрать сайт: `python tools/build_site.py` и проверить: `python tools/check_site.py`.

Alt-текст фото берётся из i18n (`about.portrait.alt`), отдельно его задавать не нужно.
В JSON-LD (`Person.image`) фото попадёт автоматически.
