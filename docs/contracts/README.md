# docs/contracts — образцы договоров для страницы «Владельцам»

Слот для **настоящих** PDF-образцов договоров, которые агентство заключает с владельцами.
Пока файлов нет, страница `/owners/` (блок «Пример договора», `#contract`) показывает
структурированное оглавление договоров из `i18n/<lang>/owners.json` → `contract.sale` и
`contract.business` с пометкой «образец для ознакомления — окончательный текст
предоставляется при подписании» и кнопкой «Запросить образец договора».

## Какие файлы нужны

| Договор | Рекомендуемое имя | Ключ в owners.json |
|---|---|---|
| Договор на продажу недвижимости (посредничество) | `sale-mandate-<lang>.pdf` | `contract.files.sale` |
| Договор на продажу готового бизнеса | `business-sale-mandate-<lang>.pdf` | `contract.files.business` |

`<lang>` — `ru`, `en`, `me` (черногорский) и т. д. Латиница, нижний регистр, через дефис.

## Требования к PDF

- Это **образец**: без персональных данных, подписей, печатей, реальных номеров листов
  непокретности, KO/PD и адресов. Поля для заполнения — пустые линии или `[…]`.
- В шапке или колонтитуле: «Образец для ознакомления. Окончательный текст
  предоставляется при подписании» (на языке документа).
- Текст согласован юристом; номера статей законов не цитировать на сайте.
- Размер — до ~1 МБ, текстовый PDF (не скан), чтобы его можно было искать и читать
  экранным диктором.

## Как подключить

1. Положить файл в эту папку, например `docs/contracts/sale-mandate-ru.pdf`.
2. В `i18n/ru/owners.json` указать путь от корня репозитория:

   ```json
   "contract": {
     "files": {
       "sale": "docs/contracts/sale-mandate-ru.pdf",
       "business": ""
     }
   }
   ```

   Пустая строка — ссылки нет. Ключ языковой: для `en` можно указать
   `docs/contracts/sale-mandate-en.pdf`; если в языке ключ не задан, действует цепочка
   `lang → en → ru` (например, немецкая страница покажет английский PDF).
3. Шаблон `src/templates/pages/owners.html` выводит кнопку «Скачать PDF» только если
   файл реально существует (`asset_exists`), ссылка получает `?v=<hash>` (сброс кэша).
4. Добавить `"docs/contracts"` в `static_dirs` в `src/site.json`, чтобы файлы копировались
   и в сборки вне корня (`build_site.py --out …`) и `check_site.py` не считал ссылку битой.
   На GitHub Pages папка `docs/` публикуется и так (сайт собирается в корень репозитория).
5. `python tools/build_site.py --strict` и `python tools/check_site.py`.
